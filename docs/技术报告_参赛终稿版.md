## 3. 数据结构与字段定义

Schema 文件： [scievo.schema.json](/C:/Users/zheng/Desktop/MU1_SciEvo/schemas/scievo.schema.json)

核心字段：

- `record_id`：样本唯一标识。
- `track_type`：固定为 `Sci-Evo`。
- `domain`：学科域标签。
- `source`：来源元数据（title/url/doi/license/citation）。
- `initial_request`：研究目标、输入信息、用户意图、量化目标。
- `trajectory`：多步科学轨迹（thought/action/tool/observation/outcome）。
- `success_verification`：验证方式、关键指标、最终结论。
- `provenance`：构建时间、pipeline 版本、MinerU task_id、来源片段。
- `quality`：审核状态与质量分数。

## 4. 数据构建流程

1. 准备来源清单（本地 PDF + Sciverse 查询词）。
2. 调用 MinerU（本地上传）与 Sciverse（agentic-search + content）抓取文献全文。
3. 统一保存 `full.md + meta.json` 中间产物。
4. 从 Markdown 自动生成 Sci-Evo 草稿记录。
5. 使用 JSON Schema 自动校验。
6. 切分 `train/valid/test`。

## 5. MinerU 工具链使用说明（赛题硬性要求）
