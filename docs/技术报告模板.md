## 3. 数据结构设计（Schema）

本项目使用 `schemas/scievo.schema.json`，核心字段如下：

- `initial_request`: 研究任务起点（目标、输入信息、意图、量化目标）
- `trajectory`: 多步推理与实验轨迹（thought/action/tool/parameters/observation/outcome）
- `success_verification`: 验证手段、关键指标、最终结论
- `provenance`: 构建时间、流水线版本、MinerU使用信息、来源片段
- `quality`: 审核状态与质量分数

## 4. 数据构建流程

1. 准备文献 URL 列表（`configs/paper_urls.example.csv`）。
2. 调用 MinerU API 解析文献：
   - 精准 API（推荐，需 Token）：`/api/v4/extract/task`
   - Agent API（免 Token）：`/api/v1/agent/parse/url`
3. 下载并保存 Markdown 中间结果到 `data/interim/markdown/`。
4. 将结构化样例转换为 Sci-Evo JSONL。
5. 使用 JSON Schema 自动校验。

## 5. MinerU 使用说明（赛题要求项）

- 使用工具链：`MinerU API`
- 用途：文献结构化解析（PDF -> Markdown/JSON）
- 关键参数：
  - `model_version`: `vlm`（精准 API）
  - `enable_table`: `true`
  - `enable_formula`: `true`
- 产出：解析中间文件 + 可追踪 task_id
